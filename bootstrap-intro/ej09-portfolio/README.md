# Portfolio Profesional · Nicolás Caro García

Portfolio web personal desarrollado como **Entrega 1 de la UD6 (Estructura, contenido y maquetación)** en el módulo de **Diseño de Interfaces Web** (2.º CFGS Desarrollo de Aplicaciones Web - MEDAC).

🔗 **Web publicada en GitHub Pages:** https://nicolascaro.github.io/portfolio/  
📂 **Repositorio público:** https://github.com/nicolascaro/portfolio

## Tecnologías utilizadas
- **HTML5** semántico y validado con W3C Validator
- **CSS3** (hoja de estilos mínima en `css/estilos.css`)
- **Bootstrap 5.3** (rejilla responsive, utilidades, navbar `sticky-top`, cards, badges, accordion y formulario)
- **Bootstrap Icons 1.11**
- **Git & GitHub Pages** para control de versiones y despliegue
